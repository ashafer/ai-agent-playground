# AI Agent Playground: Reaction-Time Study

A tiny, fake reaction-time experiment used for the "Get Started Safely with AI Coding Agents" workshop. You'll use this repo to practice connecting your AI coding tool (Claude Code or Codex) to GitHub and making your first commit.

## What's here

- `data/reaction_times.csv` — 20 fake trial results across two groups (`control`, `treatment`)
- `analysis/summarize.py` — prints the mean response time per group. **It has one bug in it.**
- `notes/lab-notebook.md` — a running log; add an entry each time you make a change.

## Your task

1. Ask your AI agent to run `analysis/summarize.py` and explain the error it hits.
2. Ask it to fix the bug so the script prints a count and mean response time for both groups.
3. Add an entry to `notes/lab-notebook.md` describing what was wrong and how you fixed it.
4. Commit and push your changes to your fork.
5. Confirm the commit shows up on GitHub in your fork.

That's it — if the script runs cleanly and your notebook entry and commit are on GitHub, you're done.
